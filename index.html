AJUDA

Dúvidas frequentes

Informações para usar as ferramentas com segurança e facilidade.

Preciso instalar algum aplicativo?

Não. O NEXORA Tools funciona diretamente no navegador, no celular ou computador.

As ferramentas são gratuitas?

Sim. As ferramentas disponíveis atualmente podem ser usadas gratuitamente.

Meus arquivos são enviados para algum servidor?

As ferramentas de imagem, texto, cálculos e documentos deste projeto processam os dados diretamente no navegador.

O QR Code ou PDF não foi gerado. O que fazer?

Verifique se há conexão com a internet, pois as bibliotecas de QR Code e PDF são carregadas por CDN. Depois, atualize a página e tente novamente.
